מחברות GPU (קולאב + קגל)

לחיצה אחת פותחת את שתי המחברות בלשוניות חדשות. הדף הזה נשאר פתוח, אפשר להמשיך ליצור בפוליניישנז בזמן שהן עולות.

הפרומפט נבנה אוטומטית מ-LOCK + ACTION + סצנה + SET. אם מולא URL בשדה "תמונת רפרנס" הווידאו ייווצר ממנה כתמונת עוגן (שומר זהות ומבנה גוף). קגל רץ ברקע ואפשר להישאר בדף. קולאב לא ניתן להפעלה אוטומטית (ראה למטה).

קולאב בלבד קגל בלבד
  1. קולאב: Runtime ← Run all, הדבק את הפרומפט בתא 2.
  2. קגל: Accelerator ← GPU, Internet ← On, Save & Run All.
  3. אורך נעול: 81 פריימים (5.06 שניות).
